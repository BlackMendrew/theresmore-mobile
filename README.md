# Theresmore

一款中文文字向放置（增量）策略游戏：从一小片营地开始，靠采集、建造、研究与派工，把村庄一步步推向世界之巅。

本仓库是 **Theresmore 1.2.2 的网页 1:1 复刻版**——规则、数值、科技树、事件与文案均按原版逐行还原，数据表取自原版生产包，界面针对手机竖屏重新排版。打开网页即可游玩，无需安装。

> 登攀者世界欢迎您的到来。

## 游戏简介

你是一位新生的部族领袖。开局先选择一条道路（农业 / 采集 / 采矿，随转生次数解锁更多），为村庄带来第一份收成，然后——

- 采集 **食物、木材、石头**，修建住房与生产建筑；
- 研究 **科技**，解锁新资源、新建筑，并推进到新的纪元；
- 把 **人口** 分配到不同岗位，让产出滚起来；
- 招募 **军队**，侦察并攻略野外据点，与各个王国 **外交**、通商或开战；
- 借助 **祈祷与咒语**、**神谕** 与 **市场** 调整节奏；
- 完成 **成就**、积累 **声誉**，通过 **转生 / 超转生 / 灭世** 换取永久传承。

基本循环：**采集 → 建造 / 研究 → 派工生产 → 侦察 / 出征 / 外交 → 成就与声誉 → 转生（传承）→ 下一周目更强**。

## 系统一览

| 系统 | 内容 |
| --- | --- |
| 资源 | 30 种资源：研究点、黄金、食物、木材、石头、铜、铁、工具、奶牛、马、信念、法力、声誉……以及后期才出现的遗物、传承、代币、宝石、光明等特殊资源 |
| 生产与上限 | 每种资源有上限与每秒产量；建筑、科技、人口、祖先与转生共同决定产出 |
| 建造 | 218 座建筑，分「城市 / 定居点 / 深渊」三页，按前置科技与资源逐步解锁 |
| 研究 | 372 项科技；推进「结束远古时代 / 结束封建时代」等时代科技可进入新纪元 |
| 人口 | 人口有住房上限；在农夫、伐木工、矿工、学者等岗位间自由调配 |
| 军队 | 56 种军队单位 + 侦察兵与间谍；招募、按单位编排出征人数与出手顺序 |
| 战斗 | 出征、防守与 BOSS 战；战后有战斗报告（回合数、双方阵亡与兵种明细） |
| 世界 | 123 个可探索据点、39 个王国；侦察发现目标，外交可改善关系、通商、结盟或宣战 |
| 魔法 | 172 条祈祷与咒语（111 条常驻祈祷 + 61 条可开关咒语）；法力/时间不足时咒语会自动关闭 |
| 神谕 | 建成「神示所」后可在出征前询问神谕，预演胜负（仅「容易 / 普通」难度可用） |
| 市场 | 8 种货物买卖；买价与卖价随交易波动，并随时间回落 |
| 成就 | 214 组成就、353 个成就；部分成就按难度分档，解锁即给永久加成 |
| 转生 | 用声誉换传承（173 条传承）；转生保留特殊资源与永久加成，每局都要重新选择祖先 |
| 超转生 / 灭世 | 超转生清空传承换取长期上限加成；灭世是另一条更激进的重置路线 |
| 难度 | 容易 / 普通 / 困难 / 无望 / 神明。影响敌人数倍率、成就档位、神谕是否可用、以及「神之荣耀」建筑是否解锁 |
| 祖先 | 9 位祖先，各自提供不同的开局加成，随转生次数逐步解锁 |

## 操作说明

- 底部页签：**建造 / 研究 / 人口 / 魔法 / 军队 / 外交 / 市场**；右上角齿轮进入 **设置**（速度、难度、存档导出/导入、转生入口、成就）。
- 页签按解锁条件出现：研究出宗教才有魔法，发现王国才有外交，有市场建筑才有市场，等等。
- 点按按钮执行操作；**长按条目**查看详情（代替桌面端的悬停提示）。
- 顶栏下方的采集按钮在封建制度研究完成前一直可用，之后会消失。
- 中后期可在设置里切换游戏速度（×1 / ×10 / ×60 / ×600）。

## 小提示

- **食物归零会让除食物外的全部生产停摆**，注意随时补粮。
- 手动采集有 0.1 秒节流：点一下 +1，按住则每秒 +1。
- 资源不够时点建造 / 研究不会报错，而是**自动进入队列**并弹出队列面板（槽位需要主管科技或队列大师传承）；队列每趟最多完成一项。
- 侦察、出征、间谍都有等待倒计时（默认 60 秒，超转生会缩短，最短 3 秒）。
- 神谕只是预演：它不会真的占领据点，但战斗中阵亡的士兵一样会损失。
- 每个周目只能改一次难度，第二次改动会锁定；锁定后只有转生 / 超转生 / 软重置才能再改。

## 存档

进度自动保存在浏览器本地（localStorage），清缓存或换设备会丢失；可以在 **设置** 里导出存档文本备份，或导入别人的存档继续。进度也会在浏览器关闭前自动保存。
